## 📖 What is Medusa Bot?

Medusa is a private, fully-featured Telegram AI assistant. It handles text chat, image analysis, document reading, and live web search — all within Telegram private messages.

> 🌟 **For uncensored, unrestricted chatting — use the `/medusa` command to activate Premium AI Mode.** In this mode, the bot answers without content filters or safety restrictions.

## 💬 Bot Commands

### User Commands

| Command | Description |
|---|---|
| `/start` | Wake up the bot & view your profile |
| `/help` | Show all available commands |
| `/medusa` | Switch to Premium AI Mode 🌟 |
| `/default` | Switch to Default Mode (Unlimited) 🔓 |
| `/check` | View your plan, credits & daily usage |
| `/upgrade` | Upgrade your plan using Telegram Stars |
| `/clear` | Reset your conversation history |
| `/search` | Toggle automatic web search mode |
| `/mood <normal\|angry>` | Change the bot's personality |
| `/temp <0.1–1.0>` | Adjust AI creativity level |

### Admin / Subadmin Commands

| Command | Description |
|---|---|
| `/admin` | Open the Admin Dashboard |
| `/subadmin` | Promote or demote subadmins |
| `/export <user>` | Export a user's full data as JSON |

---

## 🔒 Privacy

- The bot **only works in private chats**. It completely ignores group messages.
- Conversation history is stored per-user and can be cleared at any time with `/clear`.
- Admins can export and view user data using `/export`.
